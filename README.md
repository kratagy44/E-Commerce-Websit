# E-Commerce Website Documentation

## Introduction
This documentation provides a comprehensive overview of the E-Commerce Website project, detailing its features, setup, and usage.

## Features
- User Authentication
- Product Listings
- Shopping Cart
- Checkout Process
- Order Management
- Admin Panel

## Installation
To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/kratagy44/E-Commerce-Websit.git
   cd E-Commerce-Websit
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

## Usage
### User Registration and Login
- Navigate to the registration page to create a new account.
- After registration, log in with your credentials.

### Browsing Products
- Explore the various categories and products listed on the homepage.

### Shopping Cart
- Add products to your cart and proceed to checkout when ready.

### Admin Panel
- Access the admin panel to manage products and orders.
